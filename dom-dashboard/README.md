# DOM Lab — Curso de Frontend

Dashboard estático em HTML, CSS e JavaScript puro para a prática de **DOM — Document Object Model**, compatível com XAMPP.

## Como executar no XAMPP

1. Copie a pasta `dom-dashboard` para `C:\xampp\htdocs\`.
2. Inicie o Apache no painel do XAMPP.
3. Abra `http://localhost/dom-dashboard/` no navegador.

Também é possível abrir o `index.html` diretamente, pois o projeto não usa banco de dados, servidor PHP ou dependências externas.

## Estrutura de pastas

```text
dom-dashboard/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── styles.css
    ├── js/
    │   └── script.js
    └── images/
        └── crypto-coin.svg
```

O `index.html` contém a estrutura semântica do dashboard, a pasta `assets/css` contém o visual responsivo com os temas Soft Light e Royal Blue, `assets/js` contém as interações e exemplos de manipulação do DOM, e `assets/images` guarda a ilustração local da moeda cripto.

## Métodos demonstrados

- `getElementById`
- `getElementsByClassName`
- `getElementsByTagName`
- `querySelector`
- `querySelectorAll`
- `innerHTML`
- `addEventListener`
- `classList.toggle(class)`
- `createElement`
- `appendChild`
